# DevSecOps Pipeline & SOAR Automation Platform

## Objective

Embed security into the software delivery lifecycle and automate investigation, triage, enrichment, and response through SOAR.

## Components

- OWASP Juice Shop
- Semgrep
- Gitleaks
- Trivy
- OWASP ZAP
- GitHub Actions
- Shuffle SOAR
- TheHive

## Workflow

Commit -> Scan -> Gate -> SOAR -> Enrich -> Respond
